# `acxy5hfo.tex` 运行条件与 Word 模板匹配检查

检查对象：

- `acxy5hfo.tex`
- `物理实验报告-模板.docx`
- 一般用例：`acxy5hfo-general-example.tex` / `acxy5hfo-general-example.pdf`

检查日期：2026-09-21。

## 1. 结论

`acxy5hfo.tex` 不能在当前 WSL/TeX Live 环境中原样编译。首个致命错误是缺少
`siunitx.sty`；即使补齐该宏包，模板指定的 Windows 字体 `SimSun` 和
`Microsoft YaHei` 在本机也不存在。

该 LaTeX 模板与 Word 模板的纸张和页边距高度接近，但封面标题、正文评分结构、
内容要求、字体字号和页脚规则都有明显差异。综合结构与视觉特征，主观匹配度约为
**60%**；这不是像素相似度，而是基于 DOCX XML 参数、文本结构和编译后 PDF 的分项判断。
从评分要求看，LaTeX 文件更像旧版或特定课程变体，不宜直接视为当前 Word 模板的等价版本。

## 2. 原模板运行条件

### 必需工具

- 编译引擎：XeLaTeX。模板使用 `fontspec` 和中文 Unicode 字符，不能直接改用 pdfLaTeX。
- 推荐驱动：`latexmk`，命令为：

  ```bash
  latexmk -xelatex -interaction=nonstopmode -file-line-error acxy5hfo.tex
  ```

- TeX Live 宏包：`ctex`、`graphicx`、`caption`、`array`、`fancyhdr`、
  `lastpage`、`geometry`、`fontspec`、`amsmath`、`amsfonts`、`ulem`、
  `gensymb`、`multirow`、`siunitx`、`etoolbox`。
- 系统字体：宋体 `SimSun`、微软雅黑 `Microsoft YaHei`。

### 当前机器实测

- XeLaTeX：已安装（TeX Live 2023）。
- `latexmk`：已安装（4.83）。
- 除 `siunitx` 外，上述宏包均可由 `kpsewhich` 找到。
- `SimSun` 与 `Microsoft YaHei` 未安装；`fc-match` 会回退到 DejaVu 字体，不能得到原设计字体。
- 原文件实编译在 `\usepackage{siunitx}` 处停止，没有生成 PDF。

若坚持原样编译，需要安装含 `siunitx` 的 TeX Live science 集合，并合法安装上述两种
Windows 字体。若只求跨平台稳定，应给字体增加回退方案，且把未使用的 `siunitx` 删除或条件加载。

### 可移植性问题

- 原文档类是 `\documentclass{article}`，没有显式声明 `a4paper`。本机的 TeX 默认纸张可能是
  A4，但换一套发行版可能变为 Letter；应显式写为 `\documentclass[a4paper]{article}`。
- `\fontsize{50pt}{18pt}` 的行距参数小于字号，不是正常的 50 pt 标题行高；多行或字体变化时可能重叠。
- 所有正文段落均取消首行缩进，与 Word 模板中大量首行缩进设置不同。
- 浮动表格可能与前置标题跨页分离。一般用例中已用 `\clearpage` 展示一种简单规避方式。
- `gensymb` 与数学符号宏包组合会给出 `\perthousand`、`\micro` 未定义提示；当前示例未使用这些命令，
  因而不是成品 PDF 的实质错误。

## 3. 与 Word 模板的分项对照

| 项目 | Word 模板 | 原 LaTeX 模板 | 判断 |
|---|---|---|---|
| 纸张 | A4，210 mm × 297 mm | 未显式指定；本机一般为 A4 | 本机匹配，跨机器有风险 |
| 页边距 | 左右约 1.905 cm，上下约 2.54 cm | 左右 2 cm，上下 2.5 cm | 很接近，误差不超过约 1 mm |
| 封面图形 | 顶部含 177.45 pt × 62.7 pt 的 WMF 校名字标 | 已加入同源“浙江大学”字标 JPG，宽 6.2 cm | 高度匹配 |
| 主标题 | “物 理 实 验 报 告”，宋体粗体 36 pt | “物理学实验I / 电子实验报告”，50 pt 两行 | 文案与尺度均不同 |
| 封面字段 | 实验名称、桌号、教师、班级、姓名、学号、日期、补做信息 | 主要字段齐全，无补做信息 | 基本字段接近，但不完整 |
| 封面落款 | “浙江大学物理实验教学中心” | 仅在每页页脚出现“……制” | 不匹配 |
| 正文字体 | 涉及宋体、黑体、仿宋等；正文多为 12 pt | 主体为宋体设定，基准字号 10 pt | 字体层级与字号不同 |
| 行距 | Word 不同段落分别使用固定 20 pt、1.5 倍等 | 全文统一 `\linespread{1.5}` | 仅大致接近 |
| 页脚 | 居中页码字段，页码设置从 0 开始 | “中心制 + 第 x 页 / 共 y 页” | 明显不同 |
| 文档页数 | Word 属性记录空白模板为 3 页 | 一般用例编译为 3 页 | 页数相同，但内容分页不可直接等同 |

## 4. 最关键的内容与评分差异

### Word 模板

- 一、预习报告：10 分；实验综述要求不超过 500 字。
- 二、实验操作与原始数据：50 分；除签名原始数据外，还要求按教师要求附实验过程图，
  并完整保留姓名、学号、教师签字和日期。
- 三、结果与分析：30 分；数据处理与结果 20 分，误差分析 10 分。
- 四、实验探讨与思考题：10 分；要求先写思考题题干再作答。
- 末尾包含 PDF 命名、上传位置、成绩查询与教学评价等注意事项。

### 原 LaTeX 模板

- 一、预习报告仍为 5 + 3 + 2 分，但实验综述写成“不超过 300 字”。
- 二、原始数据为 20 分，只提到粘贴教师签名的草稿纸图，没有实验过程图和身份信息完整性要求。
- 三、结果与分析合计 50 分：数据处理 20、误差分析 20、实验探讨 10。
- 四、思考题为 20 分，未要求先抄写题干。
- 没有 Word 模板末尾的提交与评价注意事项。

因此，两份模板虽然都采用四个大部分，但分值分配与交付要求不一致。这一差异比字体或边距更重要。

## 5. 一般用例与 QA

一般用例覆盖了封面字段、四级正文结构、公式、带单位的数值、原始图片占位框、表格、
不确定度分析和思考题。所有身份信息与数据均明确标为虚构示例。

为了能在当前机器编译，测试副本做了三项最小兼容处理：

1. 显式指定 A4；
2. 使用本机字体代替缺失的 Windows 字体；
3. 对缺失且示例未使用的 `siunitx` 作条件加载。

最终使用 `latexmk -xelatex` 成功编译；PDF 为 A4、3 页、非空。已用 `pdftotext` 核对
封面字段、各章节、表格及末页文本，并渲染检查全部 3 页。未发现未解析引用、缺字、
overfull/underfull box 或页面溢出；仅保留字体元数据和 `gensymb` 的非实质警告。

## 6. 建议

若目标是提交到当前采用该 Word 文件的课程，建议下一步直接把 LaTeX 模板升级为与 Word 要求一致的版本，
至少继续同步封面标题、四部分名称和分值、500 字限制、实验过程图要求、注意事项和页脚格式；
同时显式设为 A4，并提供 Windows/WSL 两套字体回退。
