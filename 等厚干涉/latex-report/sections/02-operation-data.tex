\section*{二、实验操作与原始数据}

\subsection*{1. 实验操作}

\subsubsection*{1.1 牛顿环测量}

\begin{enumerate}
  \item 打开钠光灯，调节目镜使十字叉丝清晰；再调节物镜和反光玻片，使牛顿环明亮、清晰。
  \item 使十字叉丝的竖线与待测暗环相切。移动显微镜跨过环心，在圆环两侧分别读取第 17 至第 6 级暗环的位置。
  \item 鼓轮始终沿同一方向逼近读数位置；越过目标时先退回若干圈，再重新沿原方向逼近。
  \item 每个位置读至 $10^{-3}\,\mathrm{mm}$，以两侧位置之差求暗环直径。
\end{enumerate}

\subsubsection*{1.2 劈尖测量}

\begin{enumerate}
  \item 调整劈尖装置和显微镜，使干涉条纹清晰，并使显微镜移动方向垂直于条纹。
  \item 沿同一方向依次读取 20 条条纹的位置 $s_1$ 至 $s_{20}$。
  \item 分别读取薄片所在位置和劈尖接触线位置，以二者之差得到 $L$。
  \item 使用逐差法计算平均条纹间距，再求薄片厚度。
\end{enumerate}
